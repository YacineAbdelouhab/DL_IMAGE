# Computer Vision – TP Submissions

## 📂 GitHub Repository (Mandatory)

Each student must create **one GitHub repository** that will be used for **all TPs during the semester**.

Inside the repository, create **one folder per TP**.

### Required structure:
```text
your-repo/
├── TP1/
├── TP2/
├── TP3/
└── README.md
```

⚠️ Do **not** create a new repository for each TP.

---

## 📤 Submission Rules

- Each TP must be placed in its corresponding folder (`TP1`, `TP2`, etc.)
- Push your work **regularly** to GitHub
- The **commit history** will be used to track progress

Late pushes will be considered late submissions.

---

##  Why GitHub?

Using GitHub allows:
- Tracking work progression over time
- Verifying submission dates
- Encouraging incremental work
- Learning tools used in real research and industry

Repositories with multiple meaningful commits are preferred.
